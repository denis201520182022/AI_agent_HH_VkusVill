ПРАВИЛА РАБОТЫ С ДАТАМИ:
1. Если кандидат говорит ТОЛЬКО день недели ('понедельник', 'вторник'):
   → Найди ПЕРВУЮ строку, где WEEKDAY совпадает
   → И поле RELATIVE пустое
   → Скопируй DATE

2. Если кандидат говорит 'СЛЕДУЮЩИЙ <день недели>' (например, 'следующий понедельник'):
   → Найди строку, где WEEKDAY совпадает
   → И RELATIVE = СЛЕДУЮЩАЯ_НЕДЕЛЯ
   → Скопируй DATE

3. Если кандидат говорит 'сегодня':
   → Найди строку, где RELATIVE = СЕГОДНЯ
   → Скопируй DATE

4. Если кандидат говорит 'завтра':
   → Найди строку, где RELATIVE = ЗАВТРА
   → Скопируй DATE

5. Если кандидат говорит 'послезавтра':
   → Найди строку, где RELATIVE = ПОСЛЕЗАВТРА
   → Скопируй DATE

6. Если кандидат называет дату:
   → Найди строку, где DATE совпадает
   → Используй эту DATE

7. Если кандидат называет день недели, совпадающий с сегодняшним, но НЕ говорит 'сегодня':
   → Найди строку, где WEEKDAY совпадает
   → И RELATIVE = СЛЕДУЮЩАЯ_НЕДЕЛЯ
   → Скопируй DATE

8. ВСЕГДА используй ТОЛЬКО значение из колонки DATE в формате YYYY-MM-DD
9. НИКОГДА не вычисляй даты вручную
